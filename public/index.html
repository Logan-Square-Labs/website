Logan Square Labs

Exploring the landscape of intelligence.

Logan Square Labs is a small, independent lab working on machine learning and the systems around it: the models themselves, the tooling that makes experiments cheap to run, and the write-ups that turn a result into something someone else can use.

How we work

  • Build it to understand it. A working implementation teaches more than a summary of one, so projects here usually start from scratch.
  • Small experiments, run often. Cheap iteration beats grand plans. Good tooling is what makes trying an idea cost an afternoon instead of a week.
  • Work in the open. Code and notes go out when they are useful to somebody, not when they are finished.

Elsewhere

Code lives on GitHub. Notes and experiments show up on the posts page.
